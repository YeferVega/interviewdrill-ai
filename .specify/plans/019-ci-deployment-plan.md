# Technical Plan 019: CI/CD, Deployment & Coverage Closure

## Objective
Operationalize the project: CI that applies the Constitution's gates, a multi-cloud deployment guide, and closure of the last coverage gaps.

## Approach
1. **Coverage first**: close `JdDocumentTextExtractor.ExtractPdf` with a PDF generated by QuestPDF (existing dependency) and `InterviewDrillDbContextFactory.GetDefaultConnectionString` with a temporary CWD pointing at a fake `appsettings.json`.
2. **CI as a mirror of the Definition of Done**: `dotnet build`, `dotnet test --collect --settings coverage.runsettings`, frontend `lint/test/build`, and the E2E gate `scripts/e2e-smoke.ps1` on a Windows runner (in-memory mode).
3. **Deployment doc**: a `DEPLOYMENT.md` with a matrix of environment variables, connection strings per cloud, migration commands and `persistence='sql-server'` verification.

## Decisions
- **A single E2E script for both modes** (Phase 4/Option B); CI uses the default in-memory mode, without hosted SQL Server.
- **Auto-generated PDF fixture**: instead of a binary `.pdf` in the repo, it is composed with QuestPDF in the test (keeps PdfPig and QuestPDF covered, without binaries).
- **Honest coverage** with a `coverage.runsettings` shared by local and CI.
- **No deployment from CI** in this spec: CI validates, it does not publish (left for another iteration).

## Work order
1. Closure tests (PDF + factory) → 2. `.github/workflows/ci.yml` → 3. `DEPLOYMENT.md` → 4. suite + E2E → 5. document specs/plan/tasks/constitution/status/master plan.
