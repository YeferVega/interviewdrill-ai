## SDD Workflow Guide

1. Use `speckit_specify` to create a specification for any new feature
2. Use `speckit_plan` to design the technical approach
3. Use `speckit_tasks` to create a task list
4. Use `speckit_implement` to execute the implementation
5. Review the constitution regularly with `speckit_constitution`
